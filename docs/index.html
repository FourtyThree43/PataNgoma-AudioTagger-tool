Engineered for Safety & Precision

PataNgoma prioritizes determinism before artificial intelligence.

🛡️

Plan / Apply Lifecycle

Preview exact tag diffs in structured JSON before committing any modifications to your audio files.

⏪

Atomic Rollbacks

Automatic pre-mutation snapshots saved in an SQLite audit journal allow one-command rollbacks anytime.

🧠

Explainable Matching

Deterministic token-sort similarity scoring with duration penalty checks and transparent confidence badges.

📁

Structured File Renamer

Reorganize directories and filenames using customizable metadata templates with cross-platform sanitization.

🔍

Duplicate Detection

Detect identical tracks across multiple bitrates and formats, automatically prioritizing lossless FLAC/WAV.

🎵

Multi-Format Support

Full support for MP3, FLAC, Opus, Ogg Vorbis, M4A, AAC, WAV, AIFF, and WMA audio formats.

7 Unified Metadata Providers

Query individual sources or merge them simultaneously with conflict resolution.

🍏 Apple iTunes

🌊 AcoustID

Get Started in Seconds

Install and run via Astral UV with zero configuration overhead.

# Install dependencies & run
git clone https://github.com/FourtyThree43/PataNgoma-AudioTagger-tool.git
cd PataNgoma-AudioTagger-tool && uv sync
uv run patangoma scan ~/Music
