Engineered for Safety & Determinism

Determinism Before Intelligence — never silently overwrite your music collection.

Plan / Apply Lifecycle

Preview exact tag diffs in structured JSON before committing any modifications to your audio files.

Atomic Rollbacks

Pre-mutation snapshots saved in an SQLite audit journal allow one-command rollbacks anytime.

Get Started in Seconds

Install and run via Astral UV with zero configuration overhead.

# 1. Clone repository
git clone https://github.com/FourtyThree43/PataNgoma-AudioTagger-tool.git
# 2. Sync dependencies
cd PataNgoma-AudioTagger-tool && uv sync
# 3. Launch interactive REPL session
uv run patangoma session
